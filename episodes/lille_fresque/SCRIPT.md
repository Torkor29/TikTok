# LOSC — version « PLAN-SÉQUENCE » (test A/B vs lille_histoire)

Même voix (episodes/lille_histoire/voix/voix_complete.mp3, 0 crédit), montage 100 % différent :
**aucune coupe**. Toute l'histoire est collée sur UNE fresque géante (fond kraft, morceaux de papier
déchiré colorés = « stations »), reliées par un ruban rouge pointillé. Une caméra glisse / zoome / dézoome
d'une station à l'autre. Tout ce qui apparaît reste collé : à la fin, la fresque est complète.

## Règles de mise en scène
- Coordonnées « monde » ; caméra = (x, y, zoom) interpolée (ease in/out) entre des images clés calées sur les mots.
- Arrivée sur une station ≈ 0,25 s AVANT le mot clé ; trajet 0,3–0,5 s (whoosh), sinon micro-zoom lent (+3 %).
- Sur un mot fort : coup de zoom (+6 %) + petite secousse, pas de flash ni glitch (on ne casse pas le plan).
- Les stations voisines dépassent sur les bords (date visible) → teasing de la suite.
- Chaque date est un drapeau toujours visible : en vue d'ensemble on lit la frise entière.
- Texte écran (hors monde) seulement pour 2 moments : « COMMENT C'EST POSSIBLE ? » et le CTA.
