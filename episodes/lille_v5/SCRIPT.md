# LOSC v5 — script seconde par seconde

**Voix** : `episodes/lille_v4/voix/voix_v4.mp3` (51,6 s, 0 crédit, aucune génération). Timings mot à mot : `lille_v4/mots.json`.
**Style** : papier découpé (gouache, bords déchirés, ombres portées, grain), 1080x1920.
**Zone utile** : x 80–900 / y 230–1520 (au-dessus : rien d'important ; à droite 950+ : boutons TikTok ; en bas 1550+ : légende).

## Fil rouge (présent toute la vidéo)
1. **Le BAROMÈTRE DU LOSC** (haut gauche, x 190 y 300) : cadran papier en demi-lune (rouge → jaune → vert),
   aiguille qui suit la « santé » du club à chaque événement, avec un léger rebond (ressort) à chaque changement.
   Valeurs : 0 s = 8 % · 3 s = 100 % · 7,5 s retour 1944 = 50 % · 13,5 s = 92 % · 15,5 s = 12 % · 19 s = 60 % ·
   21,5 s = 80 % · 29,7 s = 95 % · 31,7 s = 20 % · 33,8 s = 3 % · 37 s = 55 % · 41,8 s = 40 % · 44,3 s = 100 %.
2. **La DATE** à côté (x 470 y 300) : étiquette machine à écrire qui défile (compteur) à chaque saut dans le temps.
3. Toutes les scènes s'enchaînent **sans coupe sèche** : zoom-traversant, whip, déchirure ou raccord de forme.

## Règles de mise en scène
- Chaque phrase = **une micro-scène** avec UNE action lisible, et une **caméra qui cible l'action** (zoom serré
  sur le geste puis recul).
- Aucun plan fixe : dérive caméra permanente (±1,5 %), objets qui respirent, poussière, grain, vignette.
- Textes : mots qui tombent un par un **sur le mot dit** (jamais avant la voix), surligneurs qui se dessinent.
- Impact = coup de zoom (+6 %) + secousse courte + son grave. Jamais deux fois le même son à l'identique.

## Contrôles qualité
1. Planche d'audit de chaque asset graphique (fond clair + fond foncé) → reprise tant que ce n'est pas propre.
2. Audit son : forme d'onde + spectrogramme + pic/RMS de chaque son ; pas de clic, pas de saturation.
3. Planche de 3 images par plan (début / action / fin) → reprise des chevauchements, textes coupés, zones TikTok.
4. Rendu, puis seconde planche sur la vidéo finale + vérification de la synchro sur 6 mots clés.
