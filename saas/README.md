# Campagne GetSaaS – clips TikTok/Insta

- `sources/` : vidéos brutes du Drive de la campagne (Video_31 → Video_42).
- `clips/` : clips prêts à poster (1080x1920), `getsaas_clip_<n>_hook<k>.mp4`.
- `scripts/make_clips.py sources clips` : régénère tous les clips.

Montage appliqué (conforme aux règles de la campagne) :
- titre style Snap avec un des 4 hooks officiels + emojis 💀😭😱, affiché tout le clip ;
- recadrage léger (zoom 6–10 %) différent selon le clip → pas de repost identique ;
- son d'origine uniquement, **aucune musique ajoutée**, aucun texte/prix/promesse inventés.

À faire au moment de poster : `getsaas.fr` en lien dans la bio, compte chauffé 2 jours,
puis « Soumettre le clip » sur Content Rewards avec le lien de la vidéo.
